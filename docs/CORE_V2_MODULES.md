# Core V2 Modules

Canonical capabilities are POS, inventory, barcode, suppliers, purchases, customers, tables, QR menu, kitchen, takeaway, delivery, reservations, product variants, modifiers, weighted products, and expiry tracking.

Navigation, protected routes, and backend handlers all check enabled capabilities. Backend role permissions are evaluated separately. Owners and administrators configure business details and enabled modules from Settings; existing cafe installations receive cafe defaults automatically.
