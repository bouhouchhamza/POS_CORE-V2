- Online desktop activation: Ed25519 device proof -> public /api/license/device-activate -> licence/device/status/replay checks -> Ed25519 Vendor certificate.

- Revalidation: signed device request to /api/license/device-validate, including prior certificate/device binding and terminal revocation/status propagation.
- Effective access remains licence features intersected with enabled business modules and role permissions.
- Permanent offline is represented by offline_validity_days=null; commercial expires_at remains independently effective.
